# ScreenSnap

<img width="1920" height="1080" alt="screenshot" src="https://github.com/user-attachments/assets/3bd8cf5f-2661-4853-a1d0-74bca1ad5174" />

A single-file web screenshot utility with a Material Design 3 dark interface, powered by the headless Microlink API.

## Features

- **Viewport Presets & Custom Dimensions:** Includes common device sizes (iPhone, iPad, MacBook, 1080p, 4K, Ultra-wide), full-page capture, and aspect-ratio locking.
- **Display Scaling:** Supports 1x standard, 2x Retina, and 3x Ultra device pixel densities.
- **Execution Delay Timer:** Configurable delay (0s to 3600s) with an interactive countdown to let dynamic scripts, SPAs, and animations settle.
- **Export & Clipboard:** Download pure PNGs with custom filenames, copy image data directly to clipboard, or inspect raw captures.
- **Live Capture Metrics:** Real-time reporting of render latency, dimensions, output file size, and calculated aspect ratio.

## Getting Started

1. Save the file as `index.html`.
2. Open it directly in any modern web browser—no installations, dependencies, or local server required.
